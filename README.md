# LocalizArt: Arte por toda parte | Plataforma de Mapeamento Cultural
## Status do Projeto: Em desenvolvimento (atividade Avaliativa - Disciplina de Projeto Interdisciplinar).

O LocalizArt é uma aplicação Web projetada para otimizar o trabalho dos agentes territoriais. A ferramenta permite o registro geolocalizado e a catalogação de artistas e coletivos, transformando a coleta de dados brutos em um inventário cultural organizado e acessível.

# Sobre o Projeto
Muitos agentes culturais ainda realizam o mapeamento de seus territórios de forma manuscrita (papel e caneta), o que dificulta a análise de impacto e a continuidade das políticas públicas locais.
